## About the Project
### **Calendar** - This is a Good looking Calendar for desk. not like a Regular calendar. It having Circular ring which you have to manually put on day, date and month Which help to remember the day. And also Do not need to buy New calendar every year. 

## why i made this?
### cause i Every time I forgot the day, So I make this calendar Which help to remember me the day. And no more need to change Calendar every year.
